# BearMind · правки LT1 от 23.11

Цель первого этапа — дать эксперту доступ к компонентам, которые автоинспекция оставила, удалила или слила. Затем исправьте работу с серией и подготовьте проверку автоматического отбора.

## 1. Просмотр estimates

- Запустите браузерный просмотрщик из **Inspection → View estimates**. Дайте выбрать сессию, сохранённую версию или произвольный локальный файл estimates.
- Покажите контуры, трейсы `C` и `C + YrA`, решение автоинспекции и сохранённый балл модели. Фильтруйте отбраковку по правилам, модели и дублям. Покажите продукты слияния отдельно. Сохраняйте номера компонент из открытого файла.
- Добавьте **Previous session**, **Next session**, **Show metrics** и настройки контура. Просмотр результатов не должен записывать решение ручной инспекции или менять файлы.

## 2. Monitor и ручная инспекция

- Проверьте уже перенесённую замену `you` на `expert` и удаление пометки о времени ожидания.
- Выполните задачи 2–4 [плана от 19.11](2026-11-19-lt1-fixes-round3.md). Соберите плашки времени в одну строку. Добавьте оценку конца текущего этапа. Покажите жёлтым работу, которая пойдёт без эксперта. Выведите отдельные колонки `gSig`, `min_corr`, `min_pnr` и их предупреждения.
- Запишите необязательную причину исключения из Monitor в журнал решений. Добавьте исключение сессии и мыши в интерфейс инспекции с подтверждением состава выбранных сессий. Сохраните причины и у уже исключённых записей при повторном скане.
- Оставьте два логических процессора свободными от параллельных задач автоинспекции, когда машина это позволяет. Сохраните хэши готовых этапов.
- Добавьте **Show video** для видео после коррекции движения с переходом к моменту на трейсе. Проверьте, какой браузерный формат доступен. Для FFV1 используйте браузерное превью, а при его отсутствии подготовьте локальную копию в поддерживаемом формате. После проверки синхронизации попробуйте видео вместо фонового кадра.
- Добавьте создание облегчённых estimates при завершении CNMF-E и кнопку для уже готовых сессий. Открывайте подходящий облегчённый файл для новой ручной инспекции. Сохраняйте источник ранее начатой инспекции, потому что номера компонент могут различаться. По умолчанию **Export side files** выключен. Сохранение пишет ручной estimates, а при включённой галке также трейсы, фильтры и MAT.

- Проверьте, что обычные сессии сохраняют старые хэши, а выбранные для исправления пересчитываются с нужного этапа. Отдельно обработайте последний кадр без таймстемпа в `LT1_J05_1D`. Пересчёт LT1 выполняйте отдельно от проверки кода.

- Уточнение от 25.11. В этой работе после интерфейса и полос проверяем волны и край. Классификатор пользователь переобучает в отдельной сессии.
- Обновите проверку ML-классификации после получения экспертных меток. Сопоставьте компоненты до и после ручной инспекции с учётом перенумерации и слияний.
- Проверьте старый классификатор на входных компонентах до ручной инспекции. Используйте сохранённые предсказания, если их версия, вход и номера подтверждаются. Иначе запустите проверку на небольшой размеченной подвыборке, чтобы оценить, какие краевые компоненты модель оставила.

Держите отдельный результат для эпизода, компоненты и сессии. `LT1_J01_2D` — пример отдельных допустимых эпизодов. `LT1_J26_1D` — пример сессии, которую нужно пометить для исключения целиком. Маску до CNMF-E сравните после проверки, чтобы измерить потери нормальных клеток.
- Оценивайте краевой артефакт относительно маски видимой ткани, включая вогнутые границы. Удалённая экспертом компонента имеет общую метку удаления. Для оценки отдельно разметьте «волна», «край», «оба» и «другое». Попросите эксперта проверить небольшую выборку каждого класса и пограничные случаи.

## Проверка на LT1 25.11

- Детектор просмотрел 71 463 исходных кадра `J10_2D` и выделил единственный диапазон 64642–64651 (нумерация с нуля). По таймстемпам эпизод длился 0,370 с. Круговой сдвиг приблизил к чистому изображению часть строк. В первых кадрах большинство повреждённых строк этим способом восстановить не удалось. В режиме `auto` интерполируем эпизоды до 1 с включительно. Более длинные помечаем, а эксперт может выбрать `drop` или `interpolate` в Parameters.
- Пробный поиск волн после CNMF-E использует локальный фон трейса за 30 с и совпадение всплесков не менее чем у пяти соседних компонент. На `J01_2D` доля отмеченных кадров 0,10%, на `J26_1D` 7,08%. Для обзора применён предварительный порог 2,5%. Точность на остальных сессиях и причины удаления отдельных компонент требуют разметки.
- Для разметки найдены 76 сохранённых ручных estimates. Галерея строит изображения всех оставшихся компонент по этим файлам. Сессии без сохранённого ручного результата показаны без изображения.
- В `J03_1D` из 197 принятых CNMF-E компонент эксперт оставил 187. По точному совпадению пространственных профилей краевой детектор пометил все 10 удалённых и ещё 5 сохранённых. Это оценка подсказки по одной сессии. Причины удаления по ней ещё не размечены.
