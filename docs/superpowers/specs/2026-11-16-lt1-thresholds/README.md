На 16.11 21:41 автор выбрал пороги у 56 из 84 сессий. Пороги мышей J01, J03, J05 автор проверил после CNMF-E на ручной инспекции: компоненты хорошие. Когда автор выберет пороги остальных сессий, снимок нужно собрать заново: запустить скрипт ещё раз.

Файлы:
- `lt1_thresholds.csv` — строка на сессию:
  - длительность;
  - подсказка батча (`batch_sug_*`);
  - три метода автоподбора, пересчитанные по картам: `mirror_fdr_*`, `robust_bg_*`, `pct_margin_*` (значения, число затравок, FDR);
  - значения автора (`author_*`), их число затравок и FDR;
  - откуда выбор (`author_source`): `window` — кнопка Accept на этой сессии; `window_mouse` — кнопка «Accept for all sessions of this mouse». Её запись получает и показанная сессия (в журнале у неё есть счётчики), и остальные сессии мыши (копии, без счётчиков);
  - состояния CNMF-E и инспекции.
- `threshold_choices_log.csv` — копия журнала окна: каждый Accept, с исправлениями.
- `seeds_lowered.csv` — затравки на картах при порогах автора и при пониженных: `min_corr` −0,02 … −0,4, `min_pnr` −3 … −12. Это оценка для эксперимента с порогами (п. 29).
- `grids/<SID>_g4.npz` — сетка `mirror_fdr`: `corr_grid`, `pnr_grid`, `n_real`, `n_null`, `fdr`, `marginal_fdr`.
