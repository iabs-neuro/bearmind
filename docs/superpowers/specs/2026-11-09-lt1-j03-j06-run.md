## Что запущено

1. Записан список sha256 всех файлов восьми папок сессий в `H:\Projects\LT1\CalciumData\1_Raw`.
2. Создан корень `H:\Projects\_bearmind_test\lt1_J03_J06` с настоящей папкой `1_Raw`. В ней 8 junction (`mklink /J`), по одному на папку сессии. Папка `0_TimeStamps` не нужна: у LT1 раскладка bonsai, таймстемпы `<SID>_Mini_TS.csv` лежат в папках сессий. Так же устроена `series_lt1`: её скан тоже читал таймстемпы из папок сессий.
3. `python -m bearmind scan <корень>`: `8 sessions found, 0 excluded`, 2,8 с.
4. Батч запущен функцией окна `launcher.start_detached` (тот же процесс `python -m bearmind run <корень>`, что запускает кнопка Start). Рабочая папка и `PYTHONPATH` — worktree коммита 8285a49. Превью выключены (по умолчанию). Замок машины перед запуском был свободен.
5. Пороги: `thresholds accept-suggested` по мере готовности карт каждой сессии.
6. Ворота: `LT1_J03_1D` через сервер `inspect`, остальные — `gate <корень> <SID> not-needed` сразу после CNMF-E сессии.
7. Один ручной `retry` для `LT1_J06_2D` после падения CNMF-E.
8. После выхода батча: хэши сырых данных, данные Monitor без окна, `status`, проверка файлов экспорта.

Все мои решения записаны с `--who lt1-run-agent`. Исключение — решение `cleaned` для `LT1_J03_1D`: сервер записывает имя пользователя Windows (`User`).
